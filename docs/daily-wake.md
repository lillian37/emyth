# 每日自主唤醒

个人修改版新增功能（2026-10-31）：在原有 `schedule_wake`、`list_wakes`、`cancel_wake` 工具上支持每日重复。

## 每天固定时间

让 AI 调用：

```json
{
  "repeat": "daily",
  "time": "00:00",
  "note": "提醒她早点休息"
}
```

`time` 是手机当地时区的 24 小时制 `HH:mm`。每日模式不需要 `trigger_at`，每次触发后会自动安排下一天；今天的时刻已经过去时，从明天开始。返回值包含 `wake_id`、`repeat`、`time`、`time_zone` 和下一次的 `trigger_at`，可用于确认计划。

## 一次性模式

原调用方式继续有效：传入未来的毫秒时间戳 `trigger_at`，`repeat` 可省略或填写 `once`。旧版保存的唤醒记录仍按一次性处理，不会自动变成每日计划。

## 查询和取消

- `list_wakes`：查看重复模式、每日时刻、下次触发时间、备注和待执行状态。
- `cancel_wake`：传入 `id`（创建时的 `wake_id` 或列表中的 `id`），也可用非空 `note` 模糊匹配。会移除计划并撤销系统闹钟；取消后不会继续安排下一天。

## 调度行为

- 使用系统单次闹钟，每次接收后先持久化状态并安排下一次，再启动 AI 处理；AI 请求失败不会中断每日计划。
- 每次根据当地日期和指定时刻计算下次时间，处理时区变化和夏令时。在夏令时不存在的时刻，按系统时区规则向后调整；重复的时刻每天只触发一次。
- 手机重启、应用更新、修改时间/时区、授予精确闹钟权限，以及应用重新启动时会恢复计划。不会为关机期间错过的每一天连续补发。
- Android 强行停止应用后，系统不会继续投递闹钟；重新打开应用会恢复。若工具返回 `exact=false`，表示系统仅允许近似闹钟，实际投递可能延后。

## 验证

单元测试覆盖旧记录解析、旧时间戳调用、每日参数校验、跨日/跨年/闰日、当地时区、夏令时、重复回调、冷启动恢复与正在触发的闹钟同时发生、设备时钟回拨，以及连续多周的自动续排。

手机验证可先设置两三分钟后的每日时刻：确认首次唤醒后 `list_wakes` 已显示明天的同一时刻，再用 `cancel_wake` 取消，并确认列表中已移除该计划。
