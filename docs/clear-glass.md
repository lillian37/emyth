# 清透玻璃材质

`DisplayMaterialMode.GLASS` 使用共享 `ClearGlassSurface` 绘制聊天气泡、思考链卡片和输入框。
自定义的用户/助手气泡、思考链和输入框颜色始终优先；未自定义时，玻璃材质使用冰蓝用户气泡、
烟紫助手气泡和协调的思考链/输入框染色。其他材质沿用主题默认颜色，透明度沿用原设置。
浅色模式使用清透染色、细窄方向性高光和微弱暗边。深色模式增加识读遮罩，输入框的底色略浓。
细亮边与染色折边均向内缩进，整条描边完整落在圆角裁剪范围内；保留很淡的完整轮廓，避免
宽而矮的气泡只剩一个难以辨认的高光角。中央继续透出背景。

## 背景柔化

- 原 `interfaceRealtimeRendering` 和 `chatBubbleRealtimeBlur` 存储字段不变，保留已有开关状态。
  设置界面分别显示为“玻璃背景效果”和“聊天背景柔化”。
- 两个开关均开启、实际解析后的材质为 GLASS 时，才准备聊天壁纸的柔化图。
- 使用 Coil 的同一图片加载器处理本地文件、content URI 和网络图片；限定最长边 640 像素，
  后台执行一次半径 1 像素的分离式盒式模糊，最多保留两张处理图，不回收仍可能被 UI 引用的位图。
- 各表面按页面与自身的窗口位置裁切同一张图，匹配背景的居中裁切、图片透明度、底色和渐变。
  滚动只更新绘制位置，前景文字、图标和 Markdown 不参与模糊。
- 不使用逐气泡 RenderEffect、实时捕获或动态折射着色器；Android 8.0 起均可使用这条路径。
- 无图片、加载失败或开关关闭时保留染色与细边；自定义气泡图、输入框图优先使用原图。

聊天/思考透明度只调节玻璃的染色、边缘和阴影；背景柔化由独立开关控制。透明度达到 100%
时也移除该表面的柔化层。普通纯色和磨砂材质保留原有路径。

## 验证

`GlassBackdropGeometryTest` 覆盖居中裁切、滚动与窗口偏移、布局尚未测量；
`GlassBackdropPixelsTest` 覆盖尺寸上限、色彩与透明度保持、星点柔化及边缘采样。
由 performance 构建流程运行 JVM 测试、生成优化 APK，并核验包名、非 debuggable 和 R8 输出。

真机仍需检查滚动、键盘展开、深浅色主题以及高反差壁纸上的文字可读性。
设计效果图仅提供材质方向，未验证光学折射或真机帧率。
