# 内置提示词编辑

入口：**设置 → 内置提示词**。这一页修改的是 App 追加的固定规则，修改对所有助手生效。

可编辑范围：

- 普通聊天的代码块/ZIP、屏幕跳转、跳过回复和分气泡说明。
- 主动消息上下文规则、定时触发规则、设备事件触发规则及设备事件上下文规则。
- 常规主动消息和设备事件的合成用户指令。
- 计划唤醒的备注包装规则。
- 插件工具的自动使用引导。

每项显示用途、当前状态和内容预览，可展开默认全文。修改后保存，对之后开始的请求生效；留空保存表示不附加该段文字。恢复默认先回填草稿，保存后才移除对应覆盖值。

这里修改文字，不改变功能开关、可用工具、审批设置、屏幕跳转的程序处理或定时计划。没有自定义时仍使用旧版默认内容。自定义插件模板、世界书和助手人设继续在各自入口管理；标题、建议回复、翻译、OCR、压缩模板仍在设置的模型页面编辑。

模板中的变量以双花括号显示，例如 `{{idle_minutes}}`、`{{plugin_names}}`、`{{note}}`，具体可用变量见该项说明。变量作为原文数据替换，不执行模板代码，也不会递归解析变量值中的其他占位符。运行时不替换未声明的变量。

计划唤醒的备注是触发数据。清空“计划唤醒备注说明”或删掉 `{{note}}` 只去除额外说明，当前备注仍会以纯数据块传递，不会恢复默认指令。若希望不传递备注内容，请在“唤醒提示词”页清空该计划的备注字段。

覆盖按稳定字符串 ID 单独持久化。缺失 ID 表示使用默认；显式空字符串表示不附加。逐项保存只更新本字段，逐项恢复不清除其他规则。设置备份包含覆盖值。

每条 AI 唤醒计划的备注与提示词仍在 **设置 → 唤醒提示词** 编辑；备注和提示词同时原子保存，时间与重复方式只读。创建、取消和调整唤醒计划继续由 AI 工具完成。

## 验证

自动化覆盖旧设置默认回退、显式空值、逐项恢复、保存/读取、中文和换行、变量原文替换、非递归处理、默认文案兼容，以及唤醒备注和提示词同时更新后保持调度状态不变。

手机上可先复制一段默认规则，改一小段并保存，触发相应功能确认新请求使用修改文字；再清空保存、恢复默认，确认三种状态分别为不附加、默认或已修改。对设备事件/插件规则的验证需要先启用对应功能，编辑规则本身不会开启它们。
